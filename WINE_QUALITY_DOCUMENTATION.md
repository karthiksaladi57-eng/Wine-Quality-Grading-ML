
# Wine Quality Grading System

## Domain
Machine Learning and Predictive Analytics

## Project Title
A Decision Tree and Random Forest Comparison-Based Approach to Wine Quality Grading

## Project Description
This project predicts wine quality based on physicochemical properties using Machine Learning algorithms.

## Algorithms Used
1. Decision Tree Classifier
2. Random Forest Classifier

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Gradio

## Features
- Wine Quality Prediction
- Dataset Analysis
- Decision Tree Prediction
- Random Forest Prediction
- Model Performance Comparison
- Accuracy, Precision, Recall and F1 Score

## Application
A web-based application that predicts wine quality from chemical properties.
